**File Encryption and Decryption System Using Python**

This project is a Python-based cybersecurity application designed to protect sensitive files from unauthorized access using AES-256-GCM encryption. It allows users to securely encrypt and decrypt documents, images, PDFs, and text files with password protection. The system uses the Scrypt algorithm for secure key generation and detects incorrect passwords or file modifications. It provides a simple and user-friendly solution for maintaining data confidentiality and integrity.
